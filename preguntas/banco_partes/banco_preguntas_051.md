### 5013. ¿Cómo depurarías problemas relacionados con Apache Oozie?

**Respuesta:** Para depurar problemas relacionados con Apache Oozie sigue un orden claro: (1) reproducir el fallo de forma estable, idealmente con un test o un script mínimo que no dependa del resto del sistema; (2) usar logging y, si hace falta, breakpoints (pdb) para seguir el flujo y ver el estado en el punto de fallo; (3) aislar el componente que usa Apache Oozie y verificar su configuración y dependencias.
